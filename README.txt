Linefinder

Start locally (Python 3 required):
1. Extract this archive.
2. In a terminal, open the extracted folder.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000

Choose Open PDF, then drag across text. The result shows the page and visual line number or range. Copy reference copies the location and selected quotation.

Documents are processed in your browser and are never uploaded. All library assets are bundled.

Line numbers restart on each page. Text rows are counted from top to bottom, including headings and footers; blanks are skipped. Columns at the same height share a row number. Complex layouts may give approximate results. Scanned/image-only PDFs need OCR first. Password-protected PDFs need an unlocked copy.
